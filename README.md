# room_booking_system
A modern web application for managing room reservations.

Live App: https://room-booking-system-ashen.vercel.app/
Docs: https://giga-sigmy.github.io/room_booking_system/

Core Features
Authentication: Secure user registration and login.

Role-based Access:
Standard User: Browse room availability, create bookings, and cancel personal reservations.
Administrator: Manage rooms, users, and oversee all system bookings.

Booking Management: Real-time room search and reservation history tracking.

Responsive Design: Optimized for both desktop and mobile devices.
